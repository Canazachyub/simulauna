Corte de búsqueda: 12 de octubre de 2026. Se usó el proceso 2026-II cuando estaba publicado; para UNP, el último ordinario localizado fue 2026-I.

Criterios de implementación:

- `puntos_correcta` está expresado en la escala final.
- En UNCP, `peso` conserva el ponderado bruto oficial y `puntos_correcta = peso × 18.75`.
- En UNT, algunos números se publican para bloques de asignaturas, no para cada asignatura individual; se mantienen como cursos agrupados.
- Las comprobaciones dan exactamente 407.9, 600, 400 y 1500 puntos, respectivamente.
